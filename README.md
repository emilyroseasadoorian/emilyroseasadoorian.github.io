# Hello!

This repository contains a mockup of a creative writing archive based on my personal website, built with the [Jekyll](https://jekyllrb.com) static site generator and the [Liquid](https://shopify.github.io/liquid) templating language.

I am a lifetime (self-taught!) [Ruby](https://www.ruby-lang.org/en) developer who enjoys creating both dynamic CRUD-based sites ([Rails](https://rubyonrails.org), [Sinatra](https://sinatrarb.com)) and static pages/directories with intuitive navigation features. Web/application development is the most fulfilling for me when there is data to be organized and displayed.

My personal site, which shall remain unlinked, contains personal writing and the associated scripts (Bash/Perl/Python) that help convert it all from text files to Markdown to HTML. I have here included the design, based on [jQuery](https://jquery.com)/[Bootstrap](https://getbootstrap.com) principles, and some sample data, building it incrementally to show the progression via Git.
